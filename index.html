Research Overview

연구학교 운영 개요

본교가 추진하는 연구의 목적과 3대 과제, 그리고 학생·교사·학교가 그리는 변화의 모습입니다.

🎯 연구의 목적

개별 교사의 역량에만 의존하지 않고 하이터치와 하이테크가 상호 보완적으로 작동하는 혁신 체제를 구축합니다. 집단지성 기반 플랫폼 『HTHT 수업 네비게이터』를 자체 구축하여 우수 수업 사례를 큐레이션하고, 현장 교사의 실행연구와 마이크로 피드백이 순환하는 생태계를 조성하여 기술적 활용과 정서적 교감이 조화를 이루는 실효성 있는 수업 실행 체제를 마련합니다.

👩‍🏫

교사

학습자 주도성(Student Agency)의 3요소

‘의도성 → 자기조절 → 자기성찰’이 순환하며 주도성이 자랍니다.

STEP 01

의도성

AI 진단 데이터와 교사의 정서적 상담을 바탕으로 도전적인 학습 목표를 주도적으로 설계

STEP 02

자기조절

자신의 수준에 맞는 에듀테크 도구를 능동적으로 선택하고 학습 몰입을 유지하며 과제를 완수

STEP 03

자기성찰

마이크로 피드백으로 학습 성취를 스스로 평가하고 새로운 학습으로 환류하는 메타인지

🤝

하이터치-하이테크(HTHT)

AI 기반 맞춤형 학습(High-Tech)과 교사의 인간적 연결을 통한 고차원적 역량 교육(High-Touch)의 결합

⭐

마이크로 피드백

수업 직후 별점·한 줄 평·태그로 부담 없이 수집하는 직관적 평가로 집단지성을 형성

💬

바이브 코딩

자연어 프롬프트로 AI와 소통하며 교사가 직접 플랫폼을 설계·구축·유지보수

📎 자료 추가하는 방법

  1. GitHub 저장소에 로그인 후, 자료를 넣을 폴더로 이동합니다.
    연구보고서 → files/reports, 각종 서식 → files/forms
  2. 오른쪽 위 Add file → Upload files 클릭
  3. 파일을 드래그해 올리고 아래 Commit changes 클릭
  4. 1~2분 뒤 이 사이트를 새로고침하면 자동으로 목록에 표시됩니다. 파일 이름이 곧 제목이 되니 알아보기 쉽게 지어주세요.
💡 별도 로그인·업로드 화면이 없는 이유: 서버 없이 GitHub에 파일을 두는 방식이라 무료이면서 사이트가 절대 멈추지 않습니다. 삭제·이름변경도 GitHub에서 같은 방법으로 합니다.
